# Changelog

## 0.1.0

First public release.

- Menu bar app with a popover per account and an All view; ⌘0–9 and ⌥-click to switch.
- Providers: Claude Code, Codex and Gemini CLI from local logs; Anthropic and OpenAI Admin APIs;
  xAI, GitHub Copilot, Cursor Teams, OpenRouter and DeepSeek APIs (beta).
- Claude session and weekly limits through Claude Code's status line, with reset countdown and pace.
- Codex plan limits from its own logs.
- Any number of accounts per provider, 12 colors plus a custom color, pinned accounts in the menu bar.
- Sandboxed, read-only folder access, API keys in the Keychain, Access Log of every request.
- Homebrew formula, universal DMG with checksum.
